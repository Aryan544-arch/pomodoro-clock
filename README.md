Pomodoro Clock

A responsive Pomodoro Clock built with HTML, CSS, and JavaScript to practice JavaScript fundamentals and build a functional frontend project.

- ⏱️ Customizable session duration
- ☕ Customizable break duration
- ▶️ Start, Pause, and Resume controls
- 🔄 Automatic transition between sessions and breaks
- 🔢 Session number tracking
- 🔁 Reset functionality
- ⏳ Dynamic countdown timer

⚙️ How It Works

1. Set the desired session and break durations.
2. Click Start to begin the session.
3. The timer counts down every second.
4. When the session ends, the application automatically starts the break.
5. When the break ends, the next session starts automatically.
6. The timer can be paused, resumed, or reset whenever required.
